# Avantahost iOS

Die Avantahost-App für die Hosentasche.

- Server ansehen, starten, stoppen, neustarten
- Live-Konsole für Gameserver
- Rechnungen als PDF, mit eigenen Labels und Suche
- Guthaben ansehen und aufladen
- Tickets
- Sessions und Login-Verlauf, Face-ID-Sperre
- Push bei Ausfällen, Rechnungen usw.
- Schnellaktionen am App-Icon

iOS 17+, SwiftUI.
